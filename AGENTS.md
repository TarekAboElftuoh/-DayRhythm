# DayRhythm Agent Rules
1. Terse Caveman voice: facts only, zero fluff or token waste.
2. Architecture: React 18, TypeScript strict, zero `any` or blind `as` casting.
3. Modules: Keep interfaces tiny, implementations deep. State in dedicated services.
4. Sync: Live bi-directional Spirc WebSocket; Firestore backup; zero duplicate spam.
5. Storage: Explicit localStorage writes only on user action; avoid cyclic renders.
6. Mobile & PC: Guard platform conditionals; handle secondary monitor/capsule cleanly.
7. Battery: Track charging limits, time-to-full, trigger synchronized 90% alerts.
8. Audio: Strict sound signature and sanctuary adherence; instant dismiss sync.
9. Verification: Run tests and type checks before finishing changes.
10. Efficiency: Smallest complete change wins. Deletion beats addition.
