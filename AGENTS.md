# Project Guidelines & Agent Standards

## 1. Communication & Style (Caveman Mode Active)
- Terse voice. Fluff dead. Facts alive.
- Answer first: `[thing] [action] [reason]. [next step].`
- No pleasantries, no recap, no ceremony.
- Strict token efficiency.

## 2. Engineering Standards (Matt Pocock Skills)
- **TDD First**: Write tests for agreed seams before implementing logic.
- **Deep Modules**: Small interface, deep implementation. Information hiding.
- **Root-Cause Bug Diagnosis**: Reproduce, isolate, and formulate evidence-backed hypothesis before editing.
- **Safe Refactoring**: Structural changes bracketed by green verification tests.
- **Domain Modeling**: Enforce consistent glossary, strict naming, and clear bounded contexts.

## 3. Surgical Edits (Cavecrew & Surgical Patch)
- Narrowest responsible layer only.
- Preserve surrounding code and contracts.
- Zero collateral damage.
